# 吃点啥

一个帮助用户随机决定“今天吃什么”的小程序，内置 80 种平价、常见、可即食的食物类型，并支持类别和预算筛选。

## 功能

- 随机抽取今日食物，可按类别与人均预算缩小范围
- 涵盖面食、米饭、粉汤饺子、西式快餐、街头小吃、热锅、轻食和异国风味
- 只推荐食物类型，不接入具体店铺、外卖平台或推荐网站
- 可安装到安卓手机主屏幕，首次加载后可离线使用
- 抽取历史只保存在当前设备
