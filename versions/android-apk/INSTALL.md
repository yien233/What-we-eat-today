# 吃点啥｜安卓离线 APK 安装说明

版本：1.0.0；最低系统：Android 7.0。

1. 将 `吃点啥-安卓离线版-v1.0.0.apk` 下载或复制到手机。
2. 从手机文件管理器打开 APK。若系统要求，请仅对你正在使用的下载工具或文件管理器允许“安装未知应用”。
3. 安装完成后，从桌面打开“吃点啥”。无需账号，首次打开也可以断网使用。

应用内置 80 种食物、菜单图片、类别与预算筛选。最近抽取记录和筛选条件只保存在手机里。

此 APK 不需要联网、定位或存储权限，也不依赖 GitHub Pages、Chrome 安装提示或首次网页缓存。手机需要系统自带的 Android System WebView 来显示界面。

后续同签名版本可直接覆盖安装。卸载应用会清除本机记录；PWA 与 APK 的本机记录相互独立。
